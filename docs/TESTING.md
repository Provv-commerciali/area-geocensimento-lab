# Testing strategy

Cadastral image regressions exercise actual OpenLayers GetMap loading after EPSG:3857 → EPSG:4258 reprojection, including 1530px, ultrawide and portrait/HiDPI viewports. Requests must fit 2048×2048 and keep the geographic extent. `node scripts/verify-cadastral-overlay.mjs` is an explicit manual live-service check against a local demo server on port 3100: only the search coordinate is fixed, while AdE and OSM images are real. It verifies rendered orange pixels and saves `test-results/cadastral-overlay-live.png`; it is excluded from offline CI.

Vitest covers Zod validators, civic generation/parity/deduplication, filter semantics, structured floors, controlled vocabularies, internal subject/context many-to-many traversal, comproprietà, persistence outcomes, appraisal invariants and repository contracts. React Testing Library covers private/company/existing-registry flows, strong-identifier reuse prompts, cascade behavior, absence of interview fields from contact creation and visible database failures. Playwright smoke specifications cover login/demo entry, the restored Contact navigation, zone/street flow, contact creation/filtering, linked contexts inside Contact sheets and complex interiors.

Operational-state unit tests fix an explicit civil date and cover: no interviews, exact day age, stale threshold and boundary, overdue recall, fulfilment by a later interview and precedence. Filter tests call the same derivation used by the UI. Migration contracts verify the typed singleton, RLS and column-level update privilege; the existing persistence and migration contracts continue to prove that contact creation cannot create an interview. Playwright checks the operational column/filter and the minimal settings route.

Tests never call external APIs. Repository integration tests use deterministic in-memory fixtures; live Supabase migration verification is a separate infrastructure action because credentials are not stored. CI runs lint, strict typecheck, unit/integration tests and production build. Playwright can be run locally once the browser runtime is installed.

Database contract tests also inspect incremental authorization/workflow migrations to prevent regressions such as missing grants, anonymous access, disabled RLS, browser service-role use, security-definer bypass, bundled synthetic interviews or accidental write grants on reference tables. Live policy and RPC verification still requires an authenticated user against the dedicated Supabase LAB project.

Runtime performance contracts verify contextual repository filtering, incremental reverse-link/filter/search indexes and preservation of RLS. Browser tests retain the territorial cascade while Municipality and Street rows are fetched only after their parent selection.

Territory tests validate all 20 official Region codes, the known 2026 release counts, consistent Region → intermediate unit → Municipality relationships, multiple Regions, the Toscana → Lucca → Camaiore example, rejection of conflicting parentage and the database-backed cascade in Nuova zona. The importer dry-run against the official workbook is the release-time integration check; tests never download it from the network.

GeoCensimento unit tests cover one-feature-per-civic aggregation, shared coordinates, verified/automatic/missing counters, mixed-state precedence, filtering, URL round trips, PostGIS GeoJSON/WKT/EWKB point reads, cadastral-code territory resolution, EPSG:4258 URLs and the WMS proxy allowlist. Geography command tests prove geocoder→automatic, operator→verified, preview/cancel→no write and explicit parcel confirmation. Parser tests use a representative official payload and prove unavailable subaltern/category fields are not invented. Migration contracts cover state conversion, one association per CensusRecord, contact updates/deletion, RLS and authenticated functions. Playwright covers contact edit/delete controls, retained coordinate management in the editor, OpenLayers render, full-width map below horizontal filters, attribution, counters, contextual transfer and filter regression. Automated tests do not depend on external map services.

Milestone 3 tests inject the OCR boundary and never call a live model. Provider-schema tests cover five proposals, company/unknown results, confidence bounds and non-invention. Domain tests flag duplicate names only inside one acquisition session. React tests keep Complex photos separate from explicit Doorbell analysis and keep manual review available when OCR is disabled. Migration contracts cover the private bucket, MIME/size limits, RLS and anonymous revocation, provenance, no OCR for `COMPLEX`, zero contacts during recognition, selected-proposal confirmation through `create_census_record_lab`, optional Scala/Interno and no interview insert.

Live Supabase verification remains mandatory after migration `202609130001`: anonymous read/list/upload/delete denial; authenticated signed URL/upload/delete; path/Complex mismatch rejection; five detections producing five proposals and zero contacts; four-of-five confirmation producing exactly four records/links and zero interviews; same Interno for two subjects; retry transitions and Storage compensation. Existing Contact, territory, Complex interiors and GeoCensimento suites remain the regression gate.

The loopback OCR reference service has an explicit `/health` check. A manual local smoke test may send a real image to the multipart endpoint and must receive schema version `1`, raw text, normalized regions and reviewable proposals; this test downloads official model weights and therefore remains outside deterministic CI.
