# Project Constitution

- **C01** — This is a laboratory, not a new management product.
- **C02** — Do not build A.R.E.A. modules outside Censimento/GeoCensimento.
- **C03** — GeoCensimento will geographically represent Censimento, not create a parallel database.
- **C04** — External cadastral data, cadastral cartography and Censimento are distinct domains.
- **C05** — Paid APIs must never be called automatically during map pan or zoom.
- **C06** — Future OpenAPI calls must be server-side.
- **C07** — Secrets must never reach the browser.
- **C08** — Never invent an uncertain requirement.
- **C09** — Approved specifications prevail over agent initiative.
- **C10** — Documentation and code remain synchronized.
- **C11** — `Notizia` never automatically enables `Perizia Immobiliare`.
- **C12** — A Complex supports multiple civics/extensions.
- **C13** — A cadastral parcel does not automatically equal one property unit.

The lasting output is validated architecture, test evidence, decisions and transferable documentation. This application may be deleted after the experiment.
